# Lexeme Value Notes

本目录保存 EasierLightNovel 关于分词数据再利用的研究、决策记录和实现路线。

目录默认被 Git 忽略，以便本地保存书籍样本和审计报告；本目录下列出的决策记录会显式纳入版本控制。包含作品原文、完整边界词表或本地 benchmark 输出的文件仍必须保持本地，不提交到仓库。

## 文档

- `DECISIONS.md`：当前已经收敛的设计决策、明确拒绝的方案和仍需验证的边界。
- `ROADMAP.md`：从阶段 0 证伪报告到分析索引、覆盖率、查词日志和 Anki 导出的实施路线。
- `2026-07-31-discussion.md`：本轮讨论的事实、修正和待决问题。
